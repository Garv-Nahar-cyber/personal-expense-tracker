# Personal Expense Tracker

## About the Project
**Personal Expense Tracker** is a simple Python project that helps users keep track of their daily expenses and monthly budget. The user can set their monthly budget, add expenses with details, view a list of all recorded expenses, and check the remaining balance.

---

## Features
* **User Profile:** Personalize tracking by entering the user's name.
* **Budgeting:** Set and manage a monthly budget.
* **Expense Tracking:** Add expenses along with their name, amount, and category.
* **Expense Listing:** View all recorded expenses clearly.
* **Calculations:** Automatically calculate total spent and remaining money.
* **Alert System:** Show a warning notification when total expenses exceed the defined budget.

---

## Technologies Used
* **Python**
  * Lists & Dictionaries
  * Loops (`while`, `for`)
  * Conditional statements (`if-elif-else`)
  * Standard User Input / Output (`input()`, `print()`)

## How to Run

1. **Prerequisite:** Ensure Python is installed on your system.
2. Save the source code file as `main.py`.
3. Open your Terminal or Command Prompt.
4. Navigate to the project folder and run:
   ```bash
   python main.py
   ```

---

## How It Works

1. Upon execution, the program prompts the user to enter their **Name** and **Monthly Budget**.
2. A menu interface is displayed with the following options:
   * **1.** Add Expense
   * **2.** Show Expenses
   * **3.** Show Summary
   * **4.** Exit
3. The user selects an option by entering the corresponding number to perform the desired action.
